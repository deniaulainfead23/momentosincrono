# Glossário essencial de Banco de Dados

| Termo | Definição didática |
|---|---|
| Banco de dados | coleção estruturada de dados relacionados |
| SGBD | software que define, consulta, protege e recupera bancos de dados |
| Esquema | descrição formal das estruturas e restrições |
| Instância | estado dos dados em determinado momento |
| Metadado | dado que descreve estrutura, tipo, regra ou origem de outro dado |
| Entidade | tipo de objeto relevante para o domínio |
| Atributo | propriedade registrada sobre uma entidade ou relacionamento |
| Tupla/registro | ocorrência representada por uma linha |
| Domínio | conjunto de valores admissíveis para um atributo |
| Chave primária | atributo ou conjunto mínimo que identifica uma linha |
| Chave estrangeira | atributo que referencia uma chave candidata de outra relação |
| Integridade | manutenção da validade e coerência dos dados segundo regras |
| Transação | conjunto de operações tratado como unidade lógica |
| Consulta | solicitação declarativa de dados, normalmente com `SELECT` |
| Índice | estrutura auxiliar que pode acelerar determinados acessos |
| Normalização | organização das relações para reduzir redundâncias e anomalias |

> O significado de cada campo do projeto deve constar no dicionário de dados; este glossário explica termos gerais da disciplina.

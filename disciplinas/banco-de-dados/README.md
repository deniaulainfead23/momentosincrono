## Projeto condutor

As sete unidades acompanham a **Biblioteca Comunitária Horizonte**. O caso começa com dados do cotidiano, evolui para regras e modelo entidade-relacionamento e termina com implementação e consultas em PostgreSQL. Todos os nomes e registros usados nos scripts são sintéticos.

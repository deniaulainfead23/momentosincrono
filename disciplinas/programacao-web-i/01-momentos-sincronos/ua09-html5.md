# UA9 — Criação de páginas web com HTML5

**Disciplina:** Programação Web I  
**Material autoral:** síntese didática, não reprodução de material de outra plataforma.

## Objetivo

Utilizar elementos semânticos, multimídia, validação nativa e recursos do HTML moderno.

## Síntese conceitual

HTML5 ampliou os elementos semânticos e os controles de formulário. A escolha correta do elemento melhora acessibilidade, manutenção e interpretação por agentes de usuário.

## Aplicação prática

Produza uma página de portfólio com header, nav, main, article, aside, figure, áudio ou vídeo com alternativa textual e formulário com tipos apropriados.

## Roteiro de verificação

- A solução apresenta separação entre estrutura, apresentação e comportamento?
- Os nomes dos elementos e variáveis comunicam sua finalidade?
- O resultado foi testado em mais de uma situação?
- Foram consideradas acessibilidade, validação e manutenção?

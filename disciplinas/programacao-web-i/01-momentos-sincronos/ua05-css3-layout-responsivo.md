# UA5 — Criação de páginas com CSS3

**Disciplina:** Programação Web I  
**Material autoral:** síntese didática, não reprodução de material de outra plataforma.


![Infográfico autoral da UA5 • CSS3 responsivo](../04-imagens/ua05-css3-layout-responsivo.svg)

## Objetivo

Construir layouts responsivos utilizando media queries, Flexbox e recursos modernos do CSS.

## Síntese conceitual

O layout deve adaptar o conteúdo a diferentes larguras sem esconder informações essenciais. Flexbox resolve distribuição em uma dimensão; media queries permitem ajustar regras conforme características do dispositivo.

## Aplicação prática

Transforme uma lista de produtos em grade responsiva. Use Flexbox, flex-wrap e uma media query. Teste pelo menos três larguras e registre as decisões de design.

## Roteiro de verificação

- A solução apresenta separação entre estrutura, apresentação e comportamento?
- Os nomes dos elementos e variáveis comunicam sua finalidade?
- O resultado foi testado em mais de uma situação?
- Foram consideradas acessibilidade, validação e manutenção?

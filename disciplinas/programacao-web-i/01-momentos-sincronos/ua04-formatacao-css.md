# UA4 — Criação e formatação de páginas web com CSS

**Disciplina:** Programação Web I  
**Material autoral:** síntese didática, não reprodução de material de outra plataforma.

## Objetivo

Aplicar tipografia, cores, espaçamento, bordas e o Box Model.

## Síntese conceitual

Cada elemento ocupa uma caixa formada por conteúdo, padding, border e margin. A propriedade box-sizing: border-box torna o cálculo das dimensões mais previsível. Contraste, legibilidade e espaço em branco são critérios de usabilidade.

## Aplicação prática

Reestilize uma página de campanha comunitária com paleta de três cores, escala tipográfica, cartões e estados de foco. Faça uma tabela comparando as medidas antes e depois.

## Roteiro de verificação

- A solução apresenta separação entre estrutura, apresentação e comportamento?
- Os nomes dos elementos e variáveis comunicam sua finalidade?
- O resultado foi testado em mais de uma situação?
- Foram consideradas acessibilidade, validação e manutenção?

# Exercício Prático 03 — Interface alimentada por API

Desenvolva uma página que consulte uma API pública autorizada e apresente os dados em cartões. A interface deve indicar carregamento, sucesso, resposta vazia e erro de comunicação.

## Restrições

- usar JavaScript assíncrono;
- não expor chaves secretas no navegador;
- informar a fonte dos dados;
- tratar entradas e resultados de forma segura.

## Entregáveis

Código, captura dos estados da interface, explicação da requisição e referência da API.

# Exercício Prático 02 — Site acessível para um projeto social

Crie, em trio, um site de apresentação de um projeto social local. A página deve usar HTML semântico, navegação por teclado, textos alternativos, contraste adequado, formulário de contato e CSS responsivo.

## Entregáveis

- código organizado;
- demonstração em duas larguras de tela;
- checklist de acessibilidade;
- breve justificativa das decisões.

## Critérios

| Critério | Pontos |
|---|---:|
| Estrutura semântica | 2,0 |
| Acessibilidade | 2,0 |
| Responsividade | 2,0 |
| Funcionamento do formulário | 2,0 |
| Documentação e referências | 2,0 |
| **Total** | **10,0** |

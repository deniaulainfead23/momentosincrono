# UA5 — Diagramas de casos de uso

**Disciplina:** Modelagem de Sistemas  
**Material autoral:** síntese didática, não reprodução de material de outra plataforma.

## Objetivo

Identificar atores, objetivos, fronteira do sistema e relações entre casos de uso.

## Síntese conceitual

Casos de uso representam objetivos observáveis de atores, não telas nem funções internas. O texto do caso de uso deve registrar fluxo principal, alternativas e condições relevantes.

## Aplicação prática

Para um sistema de atendimento, defina atores e seis casos de uso. Escreva o fluxo principal de Agendar atendimento e duas alternativas.

## Verificação de consistência

- A linguagem usada é a do domínio?
- Cada elemento possui responsabilidade clara?
- As regras podem ser verificadas?
- Os diagramas mantêm nomes e relações coerentes entre si?

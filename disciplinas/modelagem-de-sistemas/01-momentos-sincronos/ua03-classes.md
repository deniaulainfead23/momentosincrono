# UA3 — Diagramas de classe

**Disciplina:** Modelagem de Sistemas  
**Material autoral:** síntese didática, não reprodução de material de outra plataforma.

## Objetivo

Representar classes, atributos, operações, associações e multiplicidades.

## Síntese conceitual

O diagrama de classes descreve uma visão estática do domínio. Uma associação deve ter significado; multiplicidades registram quantas instâncias participam da relação. Generalização deve ser usada somente quando houver relação conceitual de tipo.

## Aplicação prática

Modele Usuário, Cliente, Pedido, ItemPedido e Produto. Inclua multiplicidades, atributos essenciais e pelo menos uma restrição textual.

## Verificação de consistência

- A linguagem usada é a do domínio?
- Cada elemento possui responsabilidade clara?
- As regras podem ser verificadas?
- Os diagramas mantêm nomes e relações coerentes entre si?

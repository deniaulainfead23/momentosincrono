# Exercício Prático 03 — Modelo UML integrado

A partir de um caso de uso escolhido, produza diagramas de classes, atividades e sequência. Os nomes das classes, mensagens, ações e regras devem ser rastreáveis ao mesmo cenário.

## Critérios

| Critério | Pontos |
|---|---:|
| Regras e requisitos | 2,0 |
| Correção dos diagramas | 3,0 |
| Coerência entre modelos | 3,0 |
| Apresentação técnica | 2,0 |
| **Total** | **10,0** |
